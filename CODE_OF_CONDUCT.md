# Verhaltenskodex

AXSafe soll ein freundlicher, respektvoller Ort sein.

* Sei respektvoll, geduldig und konstruktiv – auch bei Meinungsverschiedenheiten.
* Keine Belästigung, Beleidigung oder Diskriminierung.
* **Keine Schadsoftware, Exploits oder Anleitungen zum Umgehen von Schutzmechanismen** in Issues, Diskussionen oder Pull Requests.
* Keine privaten Daten Dritter veröffentlichen.

Verstöße bitte an den Repository-Inhaber über GitHub melden. Beiträge, die gegen diese Regeln verstoßen, können entfernt werden.
